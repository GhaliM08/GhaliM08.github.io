# بورتفوليو غالي معن

المشروع النهائي لمعسكر "من الصفر إلى البورتفوليو" من Ctrl + A.

الرابط: https://ghalim08.github.io/portfolio/

- سبعة أقسام: الواجهة، عنّي، المهارات، المشاريع، الخبرات، التعليم، التواصل.
- المشاريع تنقرأ من `data/projects.json` وتنعرض بـ JavaScript، مع أزرار تصفية (بيانات، ويب وبرمجة، تصميم).
- الوضع الداكن ينحفظ في `localStorage` ويبقى بعد تحديث الصفحة.
- متجاوب ومجرّب على عرض 360 بكسل.
- وسوم Open Graph مع صورة 1200×630 (`assets/og-image.jpg`) لبطاقة معاينة الرابط في واتساب.
