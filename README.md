# موقعي الشخصي

موقع شخصي بسيط مبني بـ HTML وCSS، يجمع ما تعلّمته في الوحدات الأولى من دورة أساسيات الويب.

## الصفحات

- `index.html`: الصفحة الرئيسية، وفيها نبذة عني، وجدول مهاراتي، وأهدافي.
- `projects.html`: مشاريعي.
- `contact.html`: نموذج تواصل معي.
